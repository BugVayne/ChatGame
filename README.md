## 🛠 Настройка окружения (Code Style)

Этот проект использует **Black** и **Isort** для автоматического форматирования кода. Мы используем `pre-commit` хуки, чтобы код в репозитории всегда был чистым.

### Как настроить локально:

1.  **Установите pre-commit**:
    ```bash
    pip install pre-commit
    ```

2.  **Активируйте хуки** (выполните один раз в корне проекта):
    ```bash
    pre-commit install
    ```

### Как это работает:
При попытке сделать коммит (`git commit`), система автоматически проверит и отформатирует ваш код.
*   Если форматирование изменилось: коммит прервется. Вам нужно просто добавить измененные файлы (`git add .`) и повторить коммит.
*   Если все хорошо: коммит пройдет успешно.
